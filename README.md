# Zomato-Delivery-Analysis-Report
Interactive Zomato Delivery Analysis dashboard built with Power BI, analyzing 5,000 orders across delivery time, weather conditions, traffic density, meal types, and delivery performance using DAX, Power Query, and data visualization.


This project is an interactive Zomato Delivery Analysis Dashboard built using Microsoft Power BI to analyze order patterns, delivery performance, weather conditions, traffic density, and customer delivery behavior.
Key Insights
- Analyzed 5,000+ orders across different months and weather conditions.
- Identified the top 3 order time slots based on order volume.
- Analyzed average delivery time by hour and identified peak delivery periods.
- Compared orders across Cloudy, Fog, Sandstorms, Stormy, Sunny, and Windy weather conditions.
- Analyzed multiple deliveries by delivery person's age.
- Evaluated Late_30_Min deliveries based on day name and road traffic density.
- Used interactive Meal Type filters for Buffet, Drinks, Meal, and Snack.
